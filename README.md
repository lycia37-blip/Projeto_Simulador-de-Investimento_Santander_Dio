# Projeto_Simulador-de-Investimento_Santander_Dio
planilha de simulação de investimento que responde 5 perguntas: Quanto eu devo investir por mês?		Por quantos anos devo investir?		Taxa de rendimento mensal?		Patrimônio Acumulado?		Dividendos Mensais?	
As respostas aparecem no próprio simulador a frente de cada pergunta, com cenários adicionais e grafico.
